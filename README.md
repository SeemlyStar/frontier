# Frontier

**Status:** Foundations v0.1 (21 Nov 2026)

Frontier is a single-player, text-based exploration game set in a low-tech fantasy world. Andrew designs and specifies it; Claude builds it. This repository holds both the design record and the game itself.

The earlier Godot/C# prototype is a separate learning project. Nothing from it is assumed here unless it is carried into this repository.

## Play

The playable build is published as a Claude artifact from [`game/`](game/). See [Tech](tech.md) for how it is built and saved.

## Status tags

- **[Decided]**: Andrew has agreed it; build on it.
- **[Provisional]**: adopted for now to see how it plays; expect to revisit.
- **[Proposed]**: Claude's proposal, built so it can be played and judged. Not agreed until Andrew moves it to Provisional or Decided.
- **[Open]**: not yet decided.
